Kairos exposes four purpose-built API services. Each has its own base URL, but they share authentication, pagination, and error conventions.

| API | Base URL | Auth | Purpose |
| --- | --- | --- | --- |
| **Market Data API** | `https://md.kairos.trade` | None | Free, key-free market data: markets, candles, trades, resolutions, perpetuals |
| **Data API** | `https://data.kairos.trade` | API key or JWT | Markets, search, sports, trader analytics, PnL, discovery |
| **Execution API** | `https://execution.kairos.trade` | API key or JWT | Order entry, cancellation, routing, combos, external signing |
| **Agora Auction API** | `https://agora.kairos.trade` | API key or JWT | Private institutional auctions with firm quotes and a WebSocket event stream |

## Conventions

- **Authentication** — the Market Data API is anonymous and free. The Data, Execution, and Agora APIs accept a Kairos API key (`X-Client-Id`, `X-Api-Key`, `X-Api-Secret`) or a session JWT, gated per-operation by scopes. See [Authentication](/guides/authentication).
- **Pagination** — cursor-based. Responses carry an opaque `nextCursor`; pass it back to fetch the next page.
- **Errors** — standard HTTP status codes with a JSON body. `401` means missing or invalid credentials, `403` means the credential lacks the required scope, and `429` means a rate limit was hit.
- **Rate limits** — per-IP on the free tier and per-key on authenticated tiers. Honor `429` with exponential backoff.
