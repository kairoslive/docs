The Kairos market data WebSocket delivers live orderbook snapshots, incremental deltas, trade tape, and price ticks for every prediction market across Polymarket, Kalshi, Predict.fun, and other supported venues. The stream is completely public — no API key or signup required. You open a single persistent connection, send a subscribe message, and the server pushes updates as they arrive.

## Connection Endpoint

Connect to the market data WebSocket at:

```bash
wss://md.kairos.trade/v1/ws
```

<Note>
  The REST Market Data API lives at `https://md.kairos.trade`. The WebSocket endpoint shares the same host with a `/v1/ws` path. Standard WebSocket port 443 (TLS) is used.
</Note>

### Trending Markets Feed

For the live-price subscription feed used by the Kairos Discover page, use the separate trending WebSocket endpoint from the Data API:

```bash
wss://data.kairos.trade/api/markets/trending/ws
```

This endpoint streams the current set of trending market IDs and their latest prices, updated as markets move. It requires an API key — see [Authentication](/authentication).

## Subscribe to Channels

After the connection is established, send a `subscribe` message to start receiving data. The server immediately sends a snapshot for each subscribed channel, then sends incremental updates as changes occur.

### Subscribe message format

```json
{
  "action": "subscribe",
  "channels": ["orderbook", "trades", "price_tick"],
  "markets": [
    "polymarket:0x1234567890abcdef1234567890abcdef12345678",
    "kalshi:KXBTC-25DEC"
  ],
  "encoding": "json"
}
```

<ParamField body="action" type="string" required>
  Always `"subscribe"` to start receiving updates, or `"unsubscribe"` to stop.
</ParamField>

<ParamField body="channels" type="string[]" required>
  One or more of: `orderbook`, `trades`, `price_tick`, `trending`.
</ParamField>

<ParamField body="markets" type="string[]" required>
  Kairos canonical market IDs in `provider:id` format, e.g. `polymarket:0xabc...` or `kalshi:KXBTC-25DEC`.
</ParamField>

<ParamField body="encoding" type="string">
  `"json"` (default) or `"protobuf"` — see [Protobuf Reference](/websocket/protobuf).
</ParamField>

### Server acknowledgement

```json
{
  "type": "subscribed",
  "channels": ["orderbook", "trades", "price_tick"],
  "markets": [
    "polymarket:0x1234567890abcdef1234567890abcdef12345678",
    "kalshi:KXBTC-25DEC"
  ]
}
```

### Unsubscribe

Send the same message shape with `"action": "unsubscribe"` to stop receiving updates for specific channels or markets.

```json
{
  "action": "unsubscribe",
  "channels": ["trades"],
  "markets": ["kalshi:KXBTC-25DEC"]
}
```

## Available Channels

### `orderbook` — Live Orderbook

The first message after subscribing is always a full snapshot. All subsequent messages are incremental deltas.

**Snapshot (`orderbook_snapshot`)**

```json
{
  "type": "orderbook_snapshot",
  "market_id": "polymarket:0x1234567890abcdef1234567890abcdef12345678",
  "sequence": 41872,
  "timestamp": "2025-01-15T14:32:00.123Z",
  "data": {
    "yes": {
      "bids": [
        { "price": "0.62", "size": "150.00" },
        { "price": "0.61", "size": "300.00" }
      ],
      "asks": [
        { "price": "0.63", "size": "100.00" },
        { "price": "0.64", "size": "250.00" }
      ]
    },
    "no": {
      "bids": [
        { "price": "0.36", "size": "100.00" }
      ],
      "asks": [
        { "price": "0.37", "size": "150.00" }
      ]
    }
  }
}
```

**Delta (`orderbook_delta`)**

```json
{
  "type": "orderbook_delta",
  "market_id": "polymarket:0x1234567890abcdef1234567890abcdef12345678",
  "sequence": 41873,
  "timestamp": "2025-01-15T14:32:01.045Z",
  "changes": [
    { "side": "yes", "type": "bid", "price": "0.62", "size": "0.00" },
    { "side": "yes", "type": "bid", "price": "0.63", "size": "200.00" }
  ]
}
```

A `size` of `"0.00"` means the price level was removed. Always apply deltas in `sequence` order.

<Warning>
  If you receive a delta with a sequence gap (e.g., you got sequence 41872 then 41875), discard your local book and resubscribe to the `orderbook` channel. Wait for the next full snapshot before applying further deltas.
</Warning>

### `trades` — Trade Tape

Emitted for every confirmed fill on the exchange.

```json
{
  "type": "trade",
  "market_id": "polymarket:0x1234567890abcdef1234567890abcdef12345678",
  "timestamp": "2025-01-15T14:32:05.210Z",
  "data": {
    "trade_id": "trade_abc123",
    "side": "yes",
    "price": "0.63",
    "size": "50.00",
    "taker_side": "buy"
  }
}
```

| Field | Description |
|---|---|
| `trade_id` | Venue-level trade identifier |
| `side` | Outcome traded (`yes` or `no`) |
| `price` | Execution price (0–1 scale) |
| `size` | Notional size in USD |
| `taker_side` | Whether the taker was buying or selling |

### `price_tick` — Price Ticks

A lightweight message emitted whenever the best bid or ask changes. Use this channel when you care about the current price but don't need the full book depth.

```json
{
  "type": "price_tick",
  "market_id": "polymarket:0x1234567890abcdef1234567890abcdef12345678",
  "timestamp": "2025-01-15T14:32:06.001Z",
  "data": {
    "yes_bid": "0.63",
    "yes_ask": "0.64",
    "last_trade_price": "0.63",
    "mid": "0.635"
  }
}
```

### `trending` — Trending Market IDs

Returns the current list of trending market IDs, refreshed periodically. Use this to seed a live-price dashboard without querying the REST endpoint repeatedly.

```json
{
  "type": "trending",
  "timestamp": "2025-01-15T14:32:00.000Z",
  "data": {
    "market_ids": [
      "polymarket:0xabc...",
      "kalshi:KXBTC-25DEC",
      "predictfun:some-market-id"
    ]
  }
}
```

<Tip>
  Use the `price_tick` channel when you need a live price indicator — it is much lower bandwidth than subscribing to the full `orderbook` channel for every market.
</Tip>

## Heartbeat and Ping-Pong

The Kairos WebSocket server sends WebSocket-level **ping frames** every 30 seconds. Your client must respond with a **pong frame**. Most WebSocket libraries handle this automatically. If the server does not receive a pong within 10 seconds of sending a ping, it closes the connection with code `1001 Going Away`.

To verify your own connection health, you can also send a JSON keepalive:

```json
{ "action": "ping" }
```

The server responds with:

```json
{ "type": "pong", "timestamp": "2025-01-15T14:33:00.000Z" }
```

## Reconnection Strategy

Network interruptions are normal. Implement the following reconnect loop:

<Steps>
  <Step title="Detect the disconnection">
    Listen for the socket `close` or `error` event. Record the time of last received message to distinguish live connections from silently stale ones.
  </Step>
  <Step title="Wait with exponential back-off">
    Delay `base_delay * 2^attempt + jitter` milliseconds before reconnecting. Cap at 30 seconds. Reset the counter after a stable connection lasting more than 60 seconds.

    ```text
    retry_delay = min(1s * 2^attempt + random(0, 1s), 30s)
    ```
  </Step>
  <Step title="Reopen the connection">
    Reconnect to `wss://md.kairos.trade/v1/ws` and resend your `subscribe` message for all channels you care about.
  </Step>
  <Step title="Rebuild from snapshot">
    The server sends fresh snapshots for all subscribed channels on reconnect. Rebuild your local state from those — never continue applying pre-disconnect deltas.
  </Step>
</Steps>

<Warning>
  Do not attempt to continue applying deltas from before a disconnect. Always rebuild from the post-reconnect snapshot to avoid stale or corrupted local state.
</Warning>

## Authentication

The market data WebSocket is **fully public**. You do not need to pass any credentials to subscribe to `orderbook`, `trades`, `price_tick`, or `trending` channels.

If Kairos introduces private channels in the future (such as your own fills or private order state), pass your API key as a query parameter during the upgrade:

```bash
wss://md.kairos.trade/v1/ws?token=<your-api-key>
```

Or as an `Authorization` header in the HTTP upgrade request (supported by most WebSocket libraries).

## Code Examples

<Tabs>
  <Tab title="JavaScript">
    ```javascript
    const WS_URL = "wss://md.kairos.trade/v1/ws";
    const MARKETS = [
      "polymarket:0x1234567890abcdef1234567890abcdef12345678",
      "kalshi:KXBTC-25DEC",
    ];

    let ws;
    let attempt = 0;
    const BASE_DELAY_MS = 1000;
    const MAX_DELAY_MS = 30000;

    function connect() {
      ws = new WebSocket(WS_URL);

      ws.addEventListener("open", () => {
        console.log("Connected to Kairos market data stream");
        attempt = 0;

        // Subscribe to orderbook, trade tape, and price ticks
        ws.send(
          JSON.stringify({
            action: "subscribe",
            channels: ["orderbook", "trades", "price_tick"],
            markets: MARKETS,
            encoding: "json",
          })
        );
      });

      ws.addEventListener("message", (event) => {
        const msg = JSON.parse(event.data);
        handleMessage(msg);
      });

      ws.addEventListener("close", (event) => {
        console.warn(`WebSocket closed: ${event.code} ${event.reason}`);
        scheduleReconnect();
      });

      ws.addEventListener("error", (err) => {
        console.error("WebSocket error:", err);
        ws.close();
      });
    }

    function scheduleReconnect() {
      const jitter = Math.random() * 1000;
      const delay = Math.min(BASE_DELAY_MS * 2 ** attempt + jitter, MAX_DELAY_MS);
      attempt++;
      console.log(`Reconnecting in ${Math.round(delay)}ms (attempt ${attempt})...`);
      setTimeout(connect, delay);
    }

    function handleMessage(msg) {
      switch (msg.type) {
        case "subscribed":
          console.log("Subscribed to channels:", msg.channels);
          break;

        case "orderbook_snapshot":
          console.log(`Snapshot for ${msg.market_id} @ seq ${msg.sequence}`);
          // Store the full book locally
          break;

        case "orderbook_delta":
          console.log(`Delta for ${msg.market_id} @ seq ${msg.sequence}`);
          // Apply changes to your local book
          for (const change of msg.changes) {
            if (change.size === "0.00") {
              // Remove this price level
            } else {
              // Upsert this price level
            }
          }
          break;

        case "trade":
          console.log(
            `Trade on ${msg.market_id}: ${msg.data.size} @ ${msg.data.price}`
          );
          break;

        case "price_tick":
          console.log(
            `Price tick on ${msg.market_id}: bid=${msg.data.yes_bid} ask=${msg.data.yes_ask}`
          );
          break;

        case "pong":
          // Heartbeat acknowledged
          break;

        default:
          console.log("Unknown message type:", msg.type);
      }
    }

    connect();
    ```

  <Tab title="Python">
    ```python
    import asyncio
    import json
    import random
    import websockets

    WS_URL = "wss://md.kairos.trade/v1/ws"
    MARKETS = [
        "polymarket:0x1234567890abcdef1234567890abcdef12345678",
        "kalshi:KXBTC-25DEC",
    ]
    BASE_DELAY = 1.0   # seconds
    MAX_DELAY = 30.0   # seconds

    # Local orderbook state: market_id -> {outcome: {bids: {price: size}, asks: {price: size}}}
    books: dict = {}


    def apply_snapshot(market_id: str, data: dict) -> None:
        books[market_id] = {"bids": {}, "asks": {}}
        for outcome, sides in data.items():
            for entry in sides.get("bids", []):
                books[market_id]["bids"][entry["price"]] = entry["size"]
            for entry in sides.get("asks", []):
                books[market_id]["asks"][entry["price"]] = entry["size"]
        print(f"Snapshot stored for {market_id}")


    def apply_delta(market_id: str, changes: list) -> None:
        if market_id not in books:
            return  # Wait for snapshot
        for change in changes:
            book_side = "bids" if change["type"] == "bid" else "asks"
            if change["size"] == "0.00":
                books[market_id][book_side].pop(change["price"], None)
            else:
                books[market_id][book_side][change["price"]] = change["size"]


    async def handle_message(msg: dict) -> None:
        msg_type = msg.get("type")

        if msg_type == "subscribed":
            print("Subscribed to channels:", msg["channels"])

        elif msg_type == "orderbook_snapshot":
            apply_snapshot(msg["market_id"], msg["data"])

        elif msg_type == "orderbook_delta":
            apply_delta(msg["market_id"], msg["changes"])

        elif msg_type == "trade":
            d = msg["data"]
            print(f"Trade on {msg['market_id']}: {d['size']} @ {d['price']}")

        elif msg_type == "price_tick":
            d = msg["data"]
            print(
                f"Price tick on {msg['market_id']}: "
                f"bid={d['yes_bid']} ask={d['yes_ask']}"
            )

        elif msg_type == "pong":
            pass  # heartbeat acknowledged

        else:
            print(f"Unknown message type: {msg_type}")


    async def run() -> None:
        attempt = 0
        while True:
            try:
                async with websockets.connect(WS_URL) as ws:
                    print("Connected to Kairos market data stream")
                    attempt = 0

                    await ws.send(json.dumps({
                        "action": "subscribe",
                        "channels": ["orderbook", "trades", "price_tick"],
                        "markets": MARKETS,
                        "encoding": "json",
                    }))

                    async for raw in ws:
                        msg = json.loads(raw)
                        await handle_message(msg)

            except (websockets.ConnectionClosed, OSError) as exc:
                delay = min(BASE_DELAY * (2 ** attempt) + random.random(), MAX_DELAY)
                attempt += 1
                print(f"Disconnected ({exc}). Reconnecting in {delay:.1f}s…")
                await asyncio.sleep(delay)


    if __name__ == "__main__":
        asyncio.run(run())
    ```

## Error Messages

If your subscribe message is malformed, the server responds with an error frame before closing or leaving the connection open:

```json
{
  "type": "error",
  "code": "INVALID_SUBSCRIBE",
  "message": "Unknown channel: 'orderbook_v2'. Valid channels: orderbook, trades, price_tick, trending."
}
```

| Error code | Meaning |
|---|---|
| `INVALID_SUBSCRIBE` | Malformed subscribe message or unknown channel |
| `UNKNOWN_MARKET` | One or more market IDs could not be resolved |
| `RATE_LIMITED` | Too many subscriptions or connections from your IP |
| `AUTH_REQUIRED` | You attempted to subscribe to a private channel without a token |
