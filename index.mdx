## APIs at a Glance

Kairos exposes four distinct API services, each optimized for a specific use case:

| API | Base URL | Purpose |
|-----|----------|---------|
| **Market Data API** | `md.kairos.trade` | Free, key-free read access to markets, candles, trades, and perpetuals |
| **Data API** | `data.kairos.trade` | Full data plane — search, sports, analytics, PnL, and discovery |
| **Execution API** | `execution.kairos.trade` | Order entry, cancellation, routing, combos, and onboarding |
| **Agora Auction API** | `agora.kairos.trade` | Private institutional auction house with WebSocket event streams |

<Note>
  The **Market Data API** is completely free and requires no signup or API key. Start streaming live data immediately.
</Note>

## Get Started in 3 Steps

<Steps>
  <Step title="Try market data for free">
    The Market Data API (`md.kairos.trade`) requires no authentication. Fetch live market data right now with a single GET request.
  </Step>
  <Step title="Get your API key">
    Sign up at [app.kairos.trade](https://app.kairos.trade) to get your API key for the Data, Execution, and Agora APIs.
  </Step>
  <Step title="Connect your venue accounts">
    Use the Execution API's onboarding endpoints to link your Polymarket, Kalshi, or Predict.fun accounts and start trading.
  </Step>
</Steps>
