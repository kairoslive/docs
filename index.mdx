## APIs at a Glance

Kairos exposes several API services, each optimized for a specific use case:

| API | Base URL | Auth | Purpose |
| --- | --- | --- | --- |
| **Market Data API** | `https://md.kairos.trade` | None | Free, key-free read access to markets, candles, trades, and perpetuals |
| **Data API** | `https://data.kairos.trade` | API key | Full data plane — search, sports, analytics, PnL, and discovery |
| **Execution API** | `https://execution.kairos.trade` | API key | Order entry, cancellation, routing, combos, and onboarding |
| **Agora Auction API** | `https://agora.kairos.trade` | API key / JWT | Private institutional auction house with a WebSocket event stream |
| **RPC API** | `https://rpc.kairos.trade/api/rpc` | API key / JWT | Account-scoped trading state (positions, balances, copy trading) |
| **RFQ Network** | `https://rfq.kairos.trade` | API key / JWT | Cross-venue request-for-quote over REST, WebSocket, and FIX |

<Note>
  The **Market Data API** is completely free and requires no signup or API key. Start fetching live data immediately.
</Note>

## Get Started in 4 Steps

<Steps>
  <Step title="Try market data for free">
    The Market Data API (`md.kairos.trade`) requires no authentication. Fetch live market data right now with a single `GET /v1/markets` request — see the [Quickstart](/quickstart).
  </Step>
  <Step title="Get your API key">
    Create an account at [app.kairos.trade](https://app.kairos.trade) and generate a key under **Settings → API Keys**. You receive a credential triple (`X-Client-Id`, `X-Api-Key`, `X-Api-Secret`) — see [Authentication](/guides/authentication).
  </Step>
  <Step title="Connect your venue accounts">
    Use the Execution API's onboarding endpoints to link your Polymarket, Kalshi, or Predict.fun account and enable trading.
  </Step>
  <Step title="Trade over WebSocket">
    Submit and cancel orders on the persistent `/ws` socket rather than polling REST — it's faster and simpler to build. See [Order Execution over WebSocket](/websocket/order-execution).
  </Step>
</Steps>
