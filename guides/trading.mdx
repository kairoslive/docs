The Kairos Execution API gives you a single interface to place, monitor, and cancel prediction market orders across Polymarket, Kalshi, and Predict.fun. This guide walks you through the complete order lifecycle — from fetching a fee quote to confirming a fill and cancelling unfilled resting orders.

<Info>
  All Execution API requests require an `Authorization: Bearer <your-api-key>` header. Get your API key at [app.kairos.trade](https://app.kairos.trade). Base URL: `https://execution.kairos.trade`.
</Info>

## Prerequisites

Before you place your first order, make sure you have:

- An active Kairos API key with execution scope
- At least one venue enabled (Polymarket, Kalshi, or Predict.fun) via the onboarding endpoints
- Sufficient balance on the target venue

## Order lifecycle

<Steps>
  <Step title="Get a fee quote">
    Always fetch a fee quote before submitting an order. The quote shows you the combined Kairos platform fee plus exchange fee so there are no surprises at fill time.

    ```bash GET /orders/fee-quote
    curl "https://execution.kairos.trade/orders/fee-quote?provider=polymarket&market_id=0xabc123&side=buy&size=50&price=0.62" \
      -H "Authorization: Bearer $KAIROS_API_KEY"
    ```

    ```python GET /orders/fee-quote
    import httpx

    resp = httpx.get(
        "https://execution.kairos.trade/orders/fee-quote",
        params={
            "provider": "polymarket",
            "market_id": "0xabc123",
            "side": "buy",
            "size": 50,
            "price": 0.62,
        },
        headers={"Authorization": f"Bearer {api_key}"},
    )
    print(resp.json())
    ```

    **Example response:**

    ```json
    {
      "platform_fee_rate": 0.0025,
      "exchange_fee_rate": 0.001,
      "total_fee_rate": 0.0035,
      "estimated_fee_usdc": 0.109,
      "net_cost_usdc": 31.109
    }
    ```
  </Step>

  <Step title="Submit an order">
    Send a `POST /orders` request with your order parameters. Kairos routes the order to the correct venue based on the `provider` field.

    ```bash POST /orders
    curl -X POST "https://execution.kairos.trade/orders" \
      -H "Authorization: Bearer $KAIROS_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "provider": "polymarket",
        "market_id": "0xabc123",
        "outcome": "YES",
        "side": "buy",
        "type": "limit",
        "price": 0.62,
        "size": 50
      }'
    ```

    ```python POST /orders
    import httpx

    payload = {
        "provider": "polymarket",
        "market_id": "0xabc123",
        "outcome": "YES",
        "side": "buy",
        "type": "limit",
        "price": 0.62,
        "size": 50,
    }

    resp = httpx.post(
        "https://execution.kairos.trade/orders",
        json=payload,
        headers={"Authorization": f"Bearer {api_key}"},
    )
    order = resp.json()
    print("Order ID:", order["order_id"])
    ```

    **Example response:**

    ```json
    {
      "order_id": "ord_2xKj9mQpLvT4",
      "provider": "polymarket",
      "market_id": "0xabc123",
      "outcome": "YES",
      "side": "buy",
      "type": "limit",
      "price": 0.62,
      "size": 50,
      "filled_size": 0,
      "remaining_size": 50,
      "status": "open",
      "created_at": "2025-01-15T14:23:05Z"
    }
    ```

    <Tip>
      Save the `order_id` from the response — you need it to poll for fills and to cancel the order.
    </Tip>
  </Step>

  <Step title="Monitor fills">
    Poll `GET /orders/{order_id}` to check the fill status of your order. When `remaining_size` reaches `0`, the order is fully filled.

    ```bash GET /orders/{order_id}
    curl "https://execution.kairos.trade/orders/ord_2xKj9mQpLvT4" \
      -H "Authorization: Bearer $KAIROS_API_KEY"
    ```

    ```python GET /orders/{order_id}
    import time
    import httpx

    order_id = "ord_2xKj9mQpLvT4"

    while True:
        resp = httpx.get(
            f"https://execution.kairos.trade/orders/{order_id}",
            headers={"Authorization": f"Bearer {api_key}"},
        )
        order = resp.json()
        status = order["status"]
        print(f"Status: {status} | Filled: {order['filled_size']} / {order['size']}")

        if status in ("filled", "cancelled", "rejected"):
            break
        time.sleep(2)
    ```

    **Order statuses:**

    | Status | Meaning |
    |---|---|
    | `open` | Resting on the book, waiting for a counterparty |
    | `partial` | Partially filled, still resting |
    | `filled` | Fully filled |
    | `cancelled` | Cancelled before full fill |
    | `rejected` | Rejected by the venue |
  </Step>

  <Step title="Cancel an order">
    If a resting order has not been filled and you want to pull it, call `POST /orders/{order_id}/cancel`.

    ```bash POST /orders/{order_id}/cancel
    curl -X POST "https://execution.kairos.trade/orders/ord_2xKj9mQpLvT4/cancel" \
      -H "Authorization: Bearer $KAIROS_API_KEY"
    ```

    ```python POST /orders/{order_id}/cancel
    resp = httpx.post(
        f"https://execution.kairos.trade/orders/{order_id}/cancel",
        headers={"Authorization": f"Bearer {api_key}"},
    )
    print(resp.json())
    ```

    **Example response:**

    ```json
    {
      "order_id": "ord_2xKj9mQpLvT4",
      "status": "cancelled",
      "cancelled_at": "2025-01-15T14:25:10Z"
    }
    ```
  </Step>
</Steps>

```bash GET /orders
curl "https://execution.kairos.trade/orders?provider=polymarket&status=open" \
  -H "Authorization: Bearer $KAIROS_API_KEY"
```

## Batch cancel

To cancel multiple specific orders at once, use `POST /orders/cancel-batch`. Pass an array of order IDs in the request body.

```bash POST /orders/cancel-batch
curl -X POST "https://execution.kairos.trade/orders/cancel-batch" \
  -H "Authorization: Bearer $KAIROS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "order_ids": [
      "ord_2xKj9mQpLvT4",
      "ord_5nRa1bWcXzY8",
      "ord_9qHf3kDsEmV2"
    ]
  }'
```

To cancel **all** your open orders on an exchange in one call, use `POST /orders/cancel-all`:

```bash POST /orders/cancel-all
curl -X POST "https://execution.kairos.trade/orders/cancel-all" \
  -H "Authorization: Bearer $KAIROS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"exchange": "polymarket"}'
```

<Warning>
  `cancel-all` cancels every open order on the specified exchange atomically. Use with care in production environments.
</Warning>

## Self-custody path (EIP-712)

If you want Kairos to never hold your private key, use the two-step self-custody flow. Your wallet signs an EIP-712 typed-data payload locally — Kairos never sees your private key.

<Steps>
  <Step title="Build unsigned intent">
    Call `POST /v2/orders/intent` with your order parameters. Kairos returns an unsigned EIP-712 typed-data payload and an `intent_id`.

    ```bash POST /v2/orders/intent
    curl -X POST "https://execution.kairos.trade/v2/orders/intent" \
      -H "Authorization: Bearer $KAIROS_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "provider": "polymarket",
        "market_id": "0xabc123",
        "outcome": "YES",
        "side": "buy",
        "type": "limit",
        "price": 0.62,
        "size": 50
      }'
    ```
  </Step>
  <Step title="Sign locally">
    Sign the returned `typed_data` payload with your wallet using `eth_signTypedData_v4`. Kairos never sees your private key.
  </Step>
  <Step title="Submit the signature">
    Post the signature and the original `intent_id` to `POST /v2/orders/submit`. Kairos validates the signature and forwards the order to the venue.

    ```bash POST /v2/orders/submit
    curl -X POST "https://execution.kairos.trade/v2/orders/submit" \
      -H "Authorization: Bearer $KAIROS_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "intent_id": "int_7gXp2mNkQwY3",
        "signature": "0xdeadbeef..."
      }'
    ```
  </Step>
</Steps>

## Rate limits and retries

Execution API requests are rate-limited. If you receive a `429 Too Many Requests` response, back off with exponential delay before retrying.

```python
import time, httpx

def post_with_retry(url, payload, headers, max_retries=5):
    delay = 1.0
    for attempt in range(max_retries):
        resp = httpx.post(url, json=payload, headers=headers)
        if resp.status_code == 429:
            time.sleep(delay)
            delay *= 2
            continue
        resp.raise_for_status()
        return resp.json()
    raise RuntimeError("Max retries exceeded")
```
