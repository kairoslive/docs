Kairos provides two complementary APIs for market data. The **Market Data API** (`md.kairos.trade`) is free and requires no API key — it gives you live prices, candles, trades, and perpetual snapshots. The **Data API** (`data.kairos.trade`) unlocks search, discovery, sports, analytics, and richer metadata for authenticated users. Together they cover every data need from a quick price check to a full quantitative backfill.

<Info>
  The Market Data API is completely free and requires no signup or API key. The Data API requires an `Authorization: Bearer <your-api-key>` header. Get your key at [app.kairos.trade](https://app.kairos.trade).
</Info>

## Live market prices

### Fetch a single market

Get current metadata and prices for one market in one call. No key required.

```bash
curl "https://md.kairos.trade/v1/markets/polymarket/0xabc123"
```

```python
import httpx

market = httpx.get(
    "https://md.kairos.trade/v1/markets/polymarket/0xabc123"
).json()

print(market["title"], "— best bid:", market["best_bid"], "best ask:", market["best_ask"])
```

### Paginate active markets

List all active markets for a provider. Results are cursor-paginated.

```bash
curl "https://md.kairos.trade/v1/markets?provider=polymarket&limit=50"
```

**Example response snippet:**

```json
{
  "markets": [
    {
      "market_id": "0xabc123",
      "title": "Will the Fed cut rates in Q1 2025?",
      "provider": "polymarket",
      "outcomes": ["YES", "NO"],
      "best_bid": 0.61,
      "best_ask": 0.63,
      "last_trade_price": 0.62,
      "volume_24h": 142800,
      "status": "active"
    }
  ],
  "next_cursor": "eyJwYWdlIjoxfQ=="
}
```

Pass `?cursor=<next_cursor>` to fetch the next page.

### Batch prices (Data API)

Fetch current prices for up to hundreds of markets in a single request using the Data API:

```bash
curl -X POST "https://data.kairos.trade/markets/batch-prices" \
  -H "Authorization: Bearer $KAIROS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "provider": "polymarket",
    "market_ids": ["0xabc123", "0xdef456", "0xghi789"]
  }'
```

## Mark prices

Fetch the latest mark (last-trade price) for up to 200 contract/token pairs at once — ideal for portfolio valuation loops.

```bash
curl "https://md.kairos.trade/v1/marks?provider=polymarket&market_ids=0xabc123,0xdef456"
```

```python
import httpx

resp = httpx.get(
    "https://md.kairos.trade/v1/marks",
    params={
        "provider": "polymarket",
        "market_ids": ",".join(["0xabc123", "0xdef456"]),
    },
)
marks = {m["market_id"]: m["mark"] for m in resp.json()["marks"]}
```

## OHLCV candles

### Single series

Fetch a candle series for one contract. Specify the interval with `resolution` (e.g. `1m`, `5m`, `1h`, `1d`).

```bash
curl "https://md.kairos.trade/v1/candles?provider=polymarket&market_id=0xabc123&outcome=YES&resolution=1h&start=2025-01-01T00:00:00Z&end=2025-01-08T00:00:00Z"
```

```python
import httpx

resp = httpx.get(
    "https://md.kairos.trade/v1/candles",
    params={
        "provider": "polymarket",
        "market_id": "0xabc123",
        "outcome": "YES",
        "resolution": "1h",
        "start": "2025-01-01T00:00:00Z",
        "end": "2025-01-08T00:00:00Z",
    },
)
candles = resp.json()["candles"]
print(f"Fetched {len(candles)} hourly candles")
```

**Example response snippet:**

```json
{
  "market_id": "0xabc123",
  "outcome": "YES",
  "resolution": "1h",
  "candles": [
    {
      "t": "2025-01-01T00:00:00Z",
      "o": 0.58,
      "h": 0.63,
      "l": 0.56,
      "c": 0.61,
      "v": 4200
    },
    {
      "t": "2025-01-01T01:00:00Z",
      "o": 0.61,
      "h": 0.65,
      "l": 0.60,
      "c": 0.64,
      "v": 6100

}
```

### Batch candles

Fetch candles for up to 200 contracts in a single HTTP request. Both the Market Data API and the Data API expose this endpoint.

<Tabs>
  <Tab title="Market Data API (free)">
    ```bash
    curl -X POST "https://md.kairos.trade/v1/candles/batch" \
      -H "Content-Type: application/json" \
      -d '{
        "provider": "polymarket",
        "resolution": "1h",
        "start": "2025-01-01T00:00:00Z",
        "end": "2025-01-08T00:00:00Z",
        "contracts": [
          {"market_id": "0xabc123", "outcome": "YES"},
          {"market_id": "0xdef456", "outcome": "YES"}
        ]
      }'
    ```
  </Tab>
  <Tab title="Data API (authenticated)">
    ```bash
    curl -X POST "https://data.kairos.trade/candles/batch" \
      -H "Authorization: Bearer $KAIROS_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "provider": "polymarket",
        "resolution": "1h",
        "start": "2025-01-01T00:00:00Z",
        "end": "2025-01-08T00:00:00Z",
        "contracts": [
          {"market_id": "0xabc123", "outcome": "YES"},
          {"market_id": "0xdef456", "outcome": "YES"}
        ]
      }'
    ```
  </Tab>
</Tabs>

```python
import httpx

body = {
    "provider": "polymarket",
    "resolution": "1d",
    "start": "2025-01-01T00:00:00Z",
    "end": "2025-01-15T00:00:00Z",
    "contracts": [
        {"market_id": mid, "outcome": "YES"}
        for mid in ["0xabc123", "0xdef456", "0xghi789"]
    ],
}

# No auth needed for the Market Data API
resp = httpx.post("https://md.kairos.trade/v1/candles/batch", json=body)
results = resp.json()["results"]
print(f"Received candle series for {len(results)} contracts")
```

## Trade history

### Recent trades

Fetch the trade tape for a contract. Use this to see recent price discovery and large fills.

```bash
curl "https://md.kairos.trade/v1/trades?provider=polymarket&market_id=0xabc123&outcome=YES&limit=100"
```

```python
resp = httpx.get(
    "https://md.kairos.trade/v1/trades",
    params={
        "provider": "polymarket",
        "market_id": "0xabc123",
        "outcome": "YES",
        "limit": 100,
    },
)
trades = resp.json()["trades"]
for t in trades[:5]:
    print(t["timestamp"], t["price"], t["size"], t["side"])
```

**Example response snippet:**

```json
{
  "trades": [
    {
      "trade_id": "trd_8hKp2",
      "timestamp": "2025-01-15T14:20:01Z",
      "price": 0.62,
      "size": 150,
      "side": "buy"
    }
  ]
}
```

### Volume and pressure metrics

Get aggregate volume and outcome-pressure metrics over a time window from either API:

```bash
# Market Data API (free)
curl "https://md.kairos.trade/v1/trades/metrics?provider=polymarket&market_id=0xabc123&outcome=YES&window=24h"

# Data API (authenticated)
curl "https://data.kairos.trade/trades/metrics?provider=polymarket&market_id=0xabc123&outcome=YES&window=24h" \
  -H "Authorization: Bearer $KAIROS_API_KEY"
```

## Market search and discovery

The Data API provides rich search and discovery endpoints that go beyond simple pagination.

### Search markets by text

```bash
curl "https://data.kairos.trade/search/markets?q=federal+reserve+2025&limit=10" \
  -H "Authorization: Bearer $KAIROS_API_KEY"
```

### Resolve a pasted URL

Paste any Polymarket, Kalshi, or Predict.fun URL and get back a canonical Kairos market record:

```bash
curl "https://data.kairos.trade/search/resolve-url?url=https%3A%2F%2Fpolymarket.com%2Fmarket%2Ffed-cut-q1-2025" \
  -H "Authorization: Bearer $KAIROS_API_KEY"
```

### Active markets cursor (Data API)

The Data API's `/markets/active` endpoint adds cursor-based pagination with richer metadata:

```bash
curl "https://data.kairos.trade/markets/active?provider=polymarket&limit=50" \
  -H "Authorization: Bearer $KAIROS_API_KEY"
```

### Batch market metadata

Fetch full metadata (rules, images, contract spec) for up to hundreds of markets:

```bash
curl -X POST "https://data.kairos.trade/markets/metadata/batch" \
  -H "Authorization: Bearer $KAIROS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "provider": "polymarket",
    "market_ids": ["0xabc123", "0xdef456"]
  }'
```

## Perpetuals snapshots

Kairos also exposes perpetual market data. Fetch a live snapshot for any venue/instrument pair:

```bash
curl "https://md.kairos.trade/v1/perpetuals/hyperliquid/BTC-PERP/snapshot"
```

**Example response snippet:**

```json
{
  "instrument": "BTC-PERP",
  "venue": "hyperliquid",
  "mark_price": 97420.50,
  "index_price": 97415.00,
  "funding_rate": 0.000112,
  "open_interest": 284000000,
  "volume_24h": 1820000000,
  "timestamp": "2025-01-15T14:30:00Z"
}
```
