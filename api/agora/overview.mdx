Agora is Kairos's private, invitation-only auction house for institutional block trades on prediction markets. Rather than hitting a public order book and incurring market impact, originators open a private auction, invite their chosen market makers, collect firm executable quotes, and settle the best price — all without revealing intent to the broader market.

## What Agora Gives You

<CardGroup cols={2}>
  <Card title="Block Trade Privacy" icon="lock">
    Auctions are visible only to the originator and the market makers they invite. Prices and sizes never appear on any public feed until settlement.
  </Card>
  <Card title="Firm Quotes" icon="file-signature">
    Invited makers submit legally executable prices and sizes. The originator can accept the best quote with confidence that it will settle.
  </Card>
  <Card title="Role-Filtered Views" icon="eye">

## Auction Lifecycle

<Steps>
  <Step title="Create the Auction">
    The originator calls `POST /v1/auctions`, specifying the instrument, side (BUY or SELL), size, expiry time, and a list of invited maker wallet addresses. Agora opens the auction and notifies the invited makers via their private invitation inbox.
  </Step>
  <Step title="Makers Receive Invitations">
    Each invited maker sees the new auction in their invitation inbox (`GET /v1/invitations`) and in their real-time WebSocket stream. Makers can optionally run `POST /v1/auctions/{auctionID}/quotes/preflight` to verify their capacity before committing.
  </Step>
  <Step title="Makers Submit Quotes">
    Invited makers call `POST /v1/auctions/{auctionID}/quotes` to submit a firm price and size. A maker can revise their quote by calling the same endpoint again — the latest submission replaces the previous one. Makers can also withdraw via `DELETE /v1/auctions/{auctionID}/quotes`.
  </Step>
  <Step title="Originator Reviews">
    The originator polls `GET /v1/auctions/{auctionID}` or watches the WebSocket stream to see incoming quotes in real time. The role-filtered view shows all quotes; each maker sees only their own.
  </Step>
  <Step title="Settlement or Cancellation">
    The originator accepts the winning quote off-platform and the auction settles, or cancels the auction via `POST /v1/auctions/{auctionID}/cancel` if no quote is satisfactory. The complete audit timeline is available at `GET /v1/auctions/{auctionID}/events`.
  </Step>
</Steps>

## Role-Filtered Views

Agora enforces strict information barriers based on your role at request time:

| Role | What You See |
|------|-------------|
| **Originator** | All quotes on your auction, full participant list, complete event timeline |
| **Invited Maker** | Your own quotes only, your own event timeline, your invitation inbox |

The same `GET /v1/auctions/{auctionID}` endpoint returns different payloads depending on which API key you authenticate with. This is by design — you never need to call a different URL based on your role.

## Endpoint Groups

Agora exposes **13 endpoints** across five groups:

<Accordion title="General — Health checks (2 endpoints)">
  | Method | Path | Description |
  |--------|------|-------------|
  | `GET` | `/healthz` | Process liveness probe |
  | `GET` | `/readyz` | Owner readiness probe |

  Both endpoints are **free and require no API key**. Use them to verify connectivity before authenticating.
</Accordion>

<Accordion title="Auctions — Core auction management (6 endpoints)">
  | Method | Path | Description |
  |--------|------|-------------|
  | `POST` | `/v1/auctions` | Create and open a private auction |
  | `GET` | `/v1/auctions` | List auctions visible to you |
  | `POST` | `/v1/auctions/preflight` | Verify originator capacity without reserving it |
  | `GET` | `/v1/auctions/{auctionID}` | Get a role-filtered auction view |
  | `GET` | `/v1/auctions/{auctionID}/events` | Get your complete role-filtered audit timeline |
  | `POST` | `/v1/auctions/{auctionID}/cancel` | Cancel an open auction |
</Accordion>

<Accordion title="Quotes — Maker quote management (3 endpoints)">
  | Method | Path | Description |
  |--------|------|-------------|
  | `POST` | `/v1/auctions/{auctionID}/quotes` | Submit or revise a firm executable quote |
  | `DELETE` | `/v1/auctions/{auctionID}/quotes` | Withdraw your active quote |
  | `POST` | `/v1/auctions/{auctionID}/quotes/preflight` | Verify price-specific quote capacity |
</Accordion>

<Accordion title="Stream — Real-time events (1 endpoint)">
  | Method | Path | Description |
  |--------|------|-------------|
  | `GET` | `/v1/stream` | Authenticated WebSocket event stream |
</Accordion>

<Accordion title="Invitations — Maker inbox (1 endpoint)">
  | Method | Path | Description |
  |--------|------|-------------|
  | `GET` | `/v1/invitations` | Read your durable private invitation inbox |
</Accordion>

## Base URL and Authentication

```
Base URL:  https://agora.kairos.trade
Auth:      Authorization: Bearer <your-api-key>
```

Every endpoint except `/healthz` and `/readyz` requires a valid API key. Obtain your key at [app.kairos.trade](https://app.kairos.trade).

<Note>
  `GET /healthz` and `GET /readyz` are **free with no authentication**. All other Agora endpoints require `Authorization: Bearer <your-api-key>`. If you receive a `401`, verify your key has the `agora` scope enabled.
</Note>

## Rate Limits

Agora enforces per-key rate limits on all authenticated endpoints. If you exceed the limit, the API returns `HTTP 429`. Back off using exponential retry with jitter — for example, wait `min(2^n * 100ms + random(0, 100ms), 30s)` between retries.

<Tip>
  Use the WebSocket stream (`GET /v1/stream`) instead of polling `GET /v1/auctions/{auctionID}` in a tight loop. The stream is more efficient and is not subject to the same REST rate limits.
</Tip>
