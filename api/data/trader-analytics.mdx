The Data API trader analytics group provides five endpoints for querying on-chain trading activity by wallet address. You can pull realized PnL time series, open and closed positions, recent fills, and top token holders for any market. Three of these endpoints are free and require no API key.

## Authentication

Endpoints marked **free** require no authentication. All others require:

```http
Authorization: Bearer <your-api-key>
```

---

## GET `/trader-stats/pnl-history/{wallet_address}` — **Free**

Get a trader's realized PnL time series by wallet address. Each data point represents the cumulative realized PnL at a point in time. This endpoint is free — no API key required.

**Path Parameters**

<ParamField path="wallet_address" type="string" required>
  The trader's wallet address (e.g., `0xAbCd1234...`).
</ParamField>

**Query Parameters**

<ParamField query="provider" type="string">
  Scope to a single venue (`polymarket`, `kalshi`, `predictfun`). Omit for all venues.
</ParamField>

<ParamField query="from" type="integer">
  Start of the time range as a Unix timestamp (seconds).
</ParamField>

<ParamField query="to" type="integer">
  End of the time range as a Unix timestamp (seconds).
</ParamField>

```bash
curl -s "https://data.kairos.trade/trader-stats/pnl-history/0xAbCd1234ef567890" \
  -G \
  --data-urlencode "provider=polymarket" \
  --data-urlencode "from=1700000000" \
  --data-urlencode "to=1700604800"
```

**Response Fields**

<ResponseField name="wallet_address" type="string">
  The queried wallet address.
</ResponseField>

<ResponseField name="provider" type="string">
  The venue this PnL data covers.
</ResponseField>

<ResponseField name="series" type="array">
  Array of PnL data points ordered by time.

  <Expandable title="series item fields">
    <ResponseField name="timestamp" type="integer">
      Unix timestamp (seconds) of the data point.
    </ResponseField>
    <ResponseField name="realized_pnl" type="number">
      Cumulative realized PnL in USD at this timestamp.
    </ResponseField>
    <ResponseField name="position" type="string">
      Description or ID of the position contributing to this PnL snapshot, if available.
    </ResponseField>
  </Expandable>
</ResponseField>

**Example response**

```json
{
  "wallet_address": "0xAbCd1234ef567890",
  "provider": "polymarket",
  "series": [
    {
      "timestamp": 1700000000,
      "realized_pnl": 120.50,
      "position": "Will the Fed cut rates in June?"
    },
    {
      "timestamp": 1700086400,
      "realized_pnl": 245.75,
      "position": "Will Bitcoin hit $100k in 2025?"
    }
  ]
}
```

## GET `/trader-stats/positions/{wallet_address}` — **Free**

Get a trader's open and closed positions along with derived performance statistics. Returns position size, entry price, current mark, unrealized PnL, and realized PnL for each position. This endpoint is free.

**Path Parameters**

<ParamField path="wallet_address" type="string" required>
  The trader's wallet address.
</ParamField>

**Query Parameters**

<ParamField query="provider" type="string">
  Scope to a single venue. Omit for all venues.
</ParamField>

<ParamField query="status" type="string">
  Filter positions by status: `open`, `closed`, or `all`. Defaults to `all`.
</ParamField>

```bash
curl -s "https://data.kairos.trade/trader-stats/positions/0xAbCd1234ef567890" \
  -G \
  --data-urlencode "provider=polymarket" \
  --data-urlencode "status=open"
```

**Example response**

```json
{
  "wallet_address": "0xAbCd1234ef567890",
  "positions": [
    {
      "market_id": "0xabc123",
      "provider": "polymarket",
      "title": "Will the Fed cut rates in June?",
      "outcome": "YES",
      "size": 500,
      "avg_entry_price": 0.38,
      "current_mark": 0.44,
      "unrealized_pnl": 30.00,
      "realized_pnl": 0.00,
      "status": "open"
    }
  ]
}
```

## GET `/trader-stats/trades/{wallet_address}` — **Free**

Get a trader's recent trade and fill history. Each record represents an executed fill with side, size, price, and timestamp. This endpoint is free.

**Path Parameters**

<ParamField path="wallet_address" type="string" required>
  The trader's wallet address.
</ParamField>

**Query Parameters**

<ParamField query="provider" type="string">
  Scope to a single venue. Omit for all venues.
</ParamField>

<ParamField query="limit" type="integer">
  Maximum fills to return. Defaults to `50`. Maximum `200`.
</ParamField>

<ParamField query="from" type="integer">
  Filter fills after this Unix timestamp.
</ParamField>

```bash
curl -s "https://data.kairos.trade/trader-stats/trades/0xAbCd1234ef567890" \
  -G \
  --data-urlencode "provider=polymarket" \
  --data-urlencode "limit=20"
```

**Example response**

```json
{
  "wallet_address": "0xAbCd1234ef567890",
  "trades": [
    {
      "trade_id": "t_001",
      "market_id": "0xabc123",
      "provider": "polymarket",
      "title": "Will the Fed cut rates in June?",
      "side": "BUY",
      "outcome": "YES",
      "size": 200,
      "price": 0.38,
      "fee": 0.40,
      "timestamp": 1700000000
    },
    {
      "trade_id": "t_002",
      "market_id": "0xabc123",
      "provider": "polymarket",
      "title": "Will the Fed cut rates in June?",
      "side": "BUY",
      "outcome": "YES",
      "size": 300,
      "price": 0.385,
      "fee": 0.58,
      "timestamp": 1700003600
    }
  ]
}
```

## GET `/top-holders`

Get the top token holders for one or more markets by number of shares held. Use this to understand concentration of ownership in a market or find large traders.

**Query Parameters**

<ParamField query="contract_id" type="string" required>
  The contract token ID (ERC-1155 token ID on Polymarket, or equivalent). For multi-outcome markets, pass the specific outcome's token ID.
</ParamField>

<ParamField query="provider" type="string" required>
  The venue (`polymarket`, `kalshi`, or `predictfun`).
</ParamField>

<ParamField query="limit" type="integer">
  Number of top holders to return. Defaults to `20`. Maximum `100`.
</ParamField>

```bash
curl -s "https://data.kairos.trade/top-holders" \
  -H "Authorization: Bearer <your-api-key>" \
  -G \
  --data-urlencode "contract_id=71321045679252212594626385532..." \
  --data-urlencode "provider=polymarket" \
  --data-urlencode "limit=10"
```

**Example response**

```json
{
  "contract_id": "71321045679252212594626385532...",
  "provider": "polymarket",
  "holders": [
    {
      "wallet_address": "0xAbCd1234ef567890",
      "shares": 25000,
      "rank": 1
    },
    {
      "wallet_address": "0x9876FeDc54321000",
      "shares": 18400,
      "rank": 2
    }
  ]
}
```

## GET `/search-traders`

Search for a trader's public profile by wallet address. Returns display metadata, total volume, win rate, and links to their on-chain activity where available.

**Query Parameters**

<ParamField query="wallet_address" type="string" required>
  The full wallet address to look up.
</ParamField>

<ParamField query="provider" type="string">
  Scope to a specific venue's profile data.
</ParamField>

```bash
curl -s "https://data.kairos.trade/search-traders" \
  -H "Authorization: Bearer <your-api-key>" \
  -G \
  --data-urlencode "wallet_address=0xAbCd1234ef567890"
```

**Example response**

```json
{
  "wallet_address": "0xAbCd1234ef567890",
  "display_name": "polywhale.eth",
  "total_volume_usd": 1240500.00,
  "realized_pnl_usd": 87400.00,
  "win_rate": 0.62,
  "markets_traded": 318,
  "providers": ["polymarket"]
}
```

<Info>
  Trader profiles are derived from on-chain data. Not every wallet has a display name — the `display_name` field may be `null` for wallets without a registered ENS name or Polymarket profile.
</Info>
