The Kairos Data API is your single entry point for everything data-related on the Kairos platform. Whether you're building a trading dashboard, backtesting strategies, analyzing trader behavior, or tracking live sports markets, the Data API gives you the structured, normalized feed you need across all supported venues.

## Base URL

All Data API requests go to:

```
https://data.kairos.trade
```

## Authentication

Most Data API endpoints require a valid API key. Pass it as a Bearer token in the `Authorization` header on every request:

```http
Authorization: Bearer <your-api-key>
```

Obtain your API key from [app.kairos.trade](https://app.kairos.trade). Endpoints marked **free** in the reference below do not require authentication.

<Note>
  Keep your API key secret. Do not embed it in client-side code or commit it to source control. Use environment variables or a secrets manager.
</Note>

## OpenAPI Specification

The machine-readable OpenAPI spec for the Data API is available at:

```
https://app.kairos.trade/openapi/data-api.yaml
```

Import it into Postman, Insomnia, or any OpenAPI-compatible tooling to explore all 68 endpoints interactively.

## Rate Limits

The Data API enforces per-key rate limits. When you exceed the limit, the API returns HTTP `429 Too Many Requests`. Back off using exponential retry — wait 1 second, then 2, then 4, and so on.

<Tip>
  Cache responses where possible. High-frequency polling of market data is better served by the [Kairos WebSocket streams](https://app.kairos.trade/docs/websocket/market-data-websocket) rather than repeated REST calls.
</Tip>

## Supported Venues

The Data API normalizes data across all Kairos-supported prediction market venues:

- **Polymarket** (`polymarket`) — USDC-collateralized binary and multi-outcome markets on Polygon
- **Kalshi** (`kalshi`) — U.S.-regulated event contracts
- **Predict.fun** (`predictfun`) — Crypto-native prediction markets

Pass the `provider` parameter to scope most endpoints to a specific venue, or omit it for cross-venue results where supported.

## Quick Start

Verify connectivity and get a list of active Polymarket markets with a single unauthenticated call (this endpoint requires auth, so substitute your key):

```bash
curl -s https://data.kairos.trade/markets/active \
  -H "Authorization: Bearer <your-api-key>" \
  -G \
  --data-urlencode "provider=polymarket" \
  --data-urlencode "limit=5"
```
