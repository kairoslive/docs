The Data API sports group gives you 19 endpoints to work with sports prediction markets across all Kairos-supported venues. You can query live games with urgency scores, browse matched cross-venue markets, pull tournament brackets, fetch season futures, and access enriched score and probability data from TxOdds — all in one normalized API. Several endpoints are free and require no API key.

## Authentication

Most sports endpoints require authentication:

```http
Authorization: Bearer <your-api-key>
```

Endpoints marked **free** below work without any credentials.

---

## GET `/sports/live-events`

Get active sports games with urgency scores and cross-provider prices. Each result includes real-time scores where available, the time remaining in the game, and best bid/ask prices across every venue that has a market on that game.

**Parameters**

<ParamField query="sport" type="string">
  Filter by sport (e.g., `nba`, `nfl`, `mlb`, `nhl`, `soccer`). Omit for all sports.
</ParamField>

<ParamField query="provider" type="string">
  Scope to a single venue. Omit for cross-venue results.
</ParamField>

```bash
curl -s "https://data.kairos.trade/sports/live-events" \
  -H "Authorization: Bearer <your-api-key>" \
  -G \
  --data-urlencode "sport=nba"
```

**Example response**

```json
{
  "events": [
    {
      "event_id": "nba-celtics-knicks-20250415",
      "sport": "nba",
      "home_team": "New York Knicks",
      "away_team": "Boston Celtics",
      "home_score": 88,
      "away_score": 94,
      "period": "4th Quarter",
      "time_remaining": "3:42",
      "urgency_score": 0.91,
      "markets": [
        {
          "provider": "polymarket",
          "market_id": "0xabc123",
          "title": "Celtics vs. Knicks — Celtics win?",
          "best_bid": 0.61,
          "best_ask": 0.63
        },
        {
          "provider": "kalshi",
          "market_id": "NBA-CEL-NYK-20250415",
          "title": "Boston Celtics to win",
          "best_bid": 0.60,
          "best_ask": 0.62
        }
      ]
    }
  ]
}
```

<Note>
  The `urgency_score` is a 0–1 value that reflects how close or high-stakes the game is. A score near 1 means the game is close and nearly over. Use it to sort events by trading interest.
</Note>

```bash
  -G \
  --data-urlencode "sport=nba" \
  --data-urlencode "limit=20"
```

## TxOdds Fixture Endpoints

The TxOdds group provides three endpoints for score timelines, win-probability history, and possession metrics from the TxOdds data feed. Use these to enrich your sports market UI with live fixture context.

---

## GET `/txodds/fixtures`

List sports fixtures with live status and win probabilities from TxOdds. Returns a paginated list of fixtures across all supported sports with current scores and win-probability values.

**Parameters**

<ParamField query="sport" type="string">
  Filter by sport. Omit for all sports.
</ParamField>

<ParamField query="status" type="string">
  Filter by fixture status: `live`, `upcoming`, or `finished`. Omit for all statuses.
</ParamField>

<ParamField query="limit" type="integer">
  Maximum fixtures to return. Defaults to `50`.
</ParamField>

```bash
curl -s "https://data.kairos.trade/txodds/fixtures" \
  -H "Authorization: Bearer <your-api-key>" \
  -G \
  --data-urlencode "sport=nba" \
  --data-urlencode "status=live"
```

---

## GET `/txodds/fixtures/{fixture_id}`

Get score, timeline, and possession metrics for one fixture. Returns the full live fixture detail including current score, period, possession percentage, and key event timeline.

**Path Parameters**

<ParamField path="fixture_id" type="string" required>
  The TxOdds fixture identifier.
</ParamField>

```bash
curl -s "https://data.kairos.trade/txodds/fixtures/txo_fixture_001" \
  -H "Authorization: Bearer <your-api-key>"
```

---

## GET `/txodds/fixtures/{fixture_id}/timeseries`

Get win-probability history and market read for one fixture. Returns a time-series of win-probability values for the fixture, allowing you to chart how market and statistical odds have evolved throughout the game.

**Path Parameters**

<ParamField path="fixture_id" type="string" required>
  The TxOdds fixture identifier.
</ParamField>

```bash
curl -s "https://data.kairos.trade/txodds/fixtures/txo_fixture_001/timeseries" \
  -H "Authorization: Bearer <your-api-key>"
```

**Example response**

```json
{
  "fixture_id": "txo_fixture_001",
  "home_team": "Boston Celtics",
  "away_team": "New York Knicks",
  "series": [
    {"timestamp": 1700000000, "home_win_prob": 0.55, "away_win_prob": 0.45},
    {"timestamp": 1700001800, "home_win_prob": 0.61, "away_win_prob": 0.39},
    {"timestamp": 1700003600, "home_win_prob": 0.58, "away_win_prob": 0.42}
  ]
}
```
