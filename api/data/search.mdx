The Data API search group gives you seven endpoints for finding markets: full-text search, combined market-and-event search, URL resolution, autocomplete suggestions, a fast simple search for overlays, and a powerful screener that filters by volume, price range, and category. All endpoints require authentication.

## Authentication

```http
Authorization: Bearer <your-api-key>
```

---

## GET `/search/markets`

Search prediction markets by free-text query. Results are ranked by relevance against market titles and descriptions across all enabled venues.

**Parameters**

<ParamField query="q" type="string" required>
  The search query string (e.g., `"Federal Reserve rate cut"`).
</ParamField>

<ParamField query="provider" type="string">
  Scope results to a single venue: `polymarket`, `kalshi`, or `predictfun`. Omit to search all venues.
</ParamField>

<ParamField query="limit" type="integer">
  Maximum number of results to return. Defaults to `20`. Maximum `100`.
</ParamField>

```bash
curl -s "https://data.kairos.trade/search/markets" \
  -H "Authorization: Bearer <your-api-key>" \
  -G \
  --data-urlencode "q=Federal Reserve rate cut" \
  --data-urlencode "provider=polymarket" \
  --data-urlencode "limit=10"
```

**Example response**

```json
{
  "results": [
    {
      "market_id": "0xabc123",
      "provider": "polymarket",
      "title": "Will the Fed cut rates in June 2025?",
      "category": "Economics",
      "best_bid": 0.42,
      "best_ask": 0.44,
      "score": 0.97
    }
  ],
  "total": 1
}
```

## GET `/search/markets-and-events`

Search both individual markets and event groups with combined relevance scoring. Use this endpoint when you want to surface parent events alongside their constituent outcome markets — for example, an election event alongside individual candidate markets.

**Parameters**

<ParamField query="q" type="string" required>
  The search query string.
</ParamField>

<ParamField query="provider" type="string">
  Scope to a single venue. Omit to search all venues.
</ParamField>

<ParamField query="limit" type="integer">
  Maximum number of results. Defaults to `20`.
</ParamField>

```bash
curl -s "https://data.kairos.trade/search/markets-and-events" \
  -H "Authorization: Bearer <your-api-key>" \
  -G \
  --data-urlencode "q=NBA Finals" \
  --data-urlencode "limit=5"
```

**Example response**

```json
{
  "results": [
    {
      "type": "event",
      "event_id": "nba-finals-2025",
      "title": "2025 NBA Finals",
      "market_count": 8
    },
    {
      "type": "market",
      "market_id": "0xdef456",
      "provider": "polymarket",
      "title": "Will the Celtics win the 2025 NBA Finals?"
    }
  ]
}
```

## GET `/search/simple`

Fast, lightweight search optimized for navbar autocomplete overlays and instant-search experiences. Returns a compact result set with minimal payload to minimize latency.

**Parameters**

<ParamField query="q" type="string" required>
  The search query string. Works well with partial words.
</ParamField>

```bash
curl -s "https://data.kairos.trade/search/simple" \
  -H "Authorization: Bearer <your-api-key>" \
  -G \
  --data-urlencode "q=bitcoin"
```

**Example response**

```json
{
  "results": [
    {"market_id": "0xabc123", "provider": "polymarket", "title": "Will Bitcoin hit $100k in 2025?"},
    {"market_id": "0xghi789", "provider": "kalshi", "market_id": "BTC-100K-25", "title": "Bitcoin above $100,000 by Dec 31"}
  ]
}
```

## GET `/search/resolve-url`

Resolve a pasted Polymarket, Kalshi, or Predict.fun market or event URL into a canonical Kairos market reference. Use this to let your users paste links from prediction market frontends and automatically identify the underlying market.

**Parameters**

<ParamField query="url" type="string" required>
  The full URL to resolve (e.g., `https://polymarket.com/event/will-the-fed-cut-rates-in-june`).
</ParamField>

```bash
curl -s "https://data.kairos.trade/search/resolve-url" \
  -H "Authorization: Bearer <your-api-key>" \
  -G \
  --data-urlencode "url=https://polymarket.com/event/will-the-fed-cut-rates-in-june"
```

**Example response**

```json
{
  "provider": "polymarket",
  "market_id": "0xabc123",
  "title": "Will the Fed cut rates in June 2025?",
  "type": "market"
}
```

<Note>
  If you pass an event URL that maps to multiple outcome markets, the response includes an `event_id` and a `markets` array containing all outcome contracts.
</Note>

## GET `/search/suggest`

Get autocomplete suggestions for a partial query string. Designed for search-as-you-type UI patterns where you want suggestions to appear after the user types two or more characters.

**Parameters**

<ParamField query="q" type="string" required>
  The partial query string to complete. Two or more characters recommended.
</ParamField>

```bash
curl -s "https://data.kairos.trade/search/suggest" \
  -H "Authorization: Bearer <your-api-key>" \
  -G \
  --data-urlencode "q=fed r"
```

**Example response**

```json
{
  "suggestions": [
    "Fed rate cut June",
    "Federal Reserve rate decision",
    "Fed reduces rates 2025"
  ]
}
```

## GET `/search/screener`

Find markets by what their order book and trade tape are doing. The screener lets you filter by volume range, price range, and category to surface active, liquid, or mispriced markets.

**Parameters**

<ParamField query="volume_min" type="number">
  Minimum 24-hour volume in USD. For example, `10000` filters to markets with at least $10,000 traded today.
</ParamField>

<ParamField query="volume_max" type="number">
  Maximum 24-hour volume in USD.
</ParamField>

<ParamField query="price_min" type="number">
  Minimum current best ask price (0–1). For example, `0.05` excludes near-zero-probability markets.
</ParamField>

<ParamField query="price_max" type="number">
  Maximum current best ask price (0–1). For example, `0.95` excludes near-certain markets.
</ParamField>

<ParamField query="category" type="string">
  Filter to a specific category (e.g., `politics`, `sports`, `crypto`, `economics`).
</ParamField>

<ParamField query="provider" type="string">
  Scope to a single venue. Omit for all venues.
</ParamField>

<ParamField query="limit" type="integer">
  Maximum results to return. Defaults to `50`.
</ParamField>

```bash
curl -s "https://data.kairos.trade/search/screener" \
  -H "Authorization: Bearer <your-api-key>" \
  -G \
  --data-urlencode "volume_min=5000" \
  --data-urlencode "price_min=0.10" \
  --data-urlencode "price_max=0.90" \
  --data-urlencode "category=politics" \
  --data-urlencode "limit=25"
```

**Example response**

```json
{
  "markets": [
    {
      "market_id": "0xabc123",
      "provider": "polymarket",
      "title": "Will the House pass the budget bill in Q2 2025?",
      "category": "politics",
      "volume_24h": 87450.00,
      "best_bid": 0.38,
      "best_ask": 0.40
    },
    {
      "market_id": "0xdef456",
      "provider": "kalshi",
      "title": "Will Biden sign an executive order on AI this month?",
      "category": "politics",
      "volume_24h": 12300.00,
      "best_bid": 0.62,
      "best_ask": 0.64
    }
  ],
  "total": 2
}
```

<Tip>
  Combine `price_min=0.10` and `price_max=0.90` to find markets that still have genuine uncertainty — a useful starting point for opportunity discovery.
</Tip>

## GET `/search/screener/presets`

Retrieve the one-click preset screens the screener offers. Each preset is a named filter configuration (e.g., "High Volume", "Near Resolution", "Big Movers") that you can apply directly to the screener or expose to end users.

```bash
curl -s "https://data.kairos.trade/search/screener/presets" \
  -H "Authorization: Bearer <your-api-key>"
```

**Example response**

```json
{
  "presets": [
    {
      "id": "high-volume",
      "label": "High Volume",
      "description": "Markets with the most 24h trading activity",
      "params": {"volume_min": 100000, "limit": 20}
    },
    {
      "id": "near-resolution",
      "label": "Near Resolution",
      "description": "Markets expiring in the next 24 hours",
      "params": {"expires_within_hours": 24, "limit": 20}
    },
    {
      "id": "long-shots",
      "label": "Long Shots",
      "description": "Markets priced below 10¢ with meaningful volume",
      "params": {"price_max": 0.10, "volume_min": 1000, "limit": 20}
    }
  ]
}
```

<Tip>
  Use the preset `params` objects as default values in your screener UI to give users a useful starting point without requiring manual configuration.
</Tip>
