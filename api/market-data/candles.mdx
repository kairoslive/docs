The Candles endpoints give you OHLCV (open, high, low, close, volume) price history for any prediction market contract on Kairos-supported venues. Use these to build price charts, backtest strategies, detect momentum, or feed machine learning pipelines. You can pull a single contract's history or batch up to 200 contracts in one HTTP call — no authentication required.

---

## Candle Resolutions

All candle endpoints accept a `resolution` parameter that controls the time bucket size for each candle:

| Value | Bucket Size |
|---|---|
| `1m` | 1 minute |
| `5m` | 5 minutes |
| `1h` | 1 hour |
| `1d` | 1 day |

## Get Candles for a Single Contract

Retrieve an OHLCV candle series for one contract over a specified time range.

```
GET /v1/candles
```

### Parameters

<ParamField query="provider" type="string" required>
  The venue the contract belongs to. Accepted values: `polymarket`, `kalshi`, `predictfun`.
</ParamField>

<ParamField query="contract_id" type="string" required>
  The contract (token) ID to retrieve candles for.
</ParamField>

<ParamField query="resolution" type="string" required>
  Candle bucket size. One of `1m`, `5m`, `1h`, `1d`.
</ParamField>

<ParamField query="from" type="integer">
  Start of the time range as a Unix timestamp (seconds). Defaults to 24 hours ago.
</ParamField>

<ParamField query="to" type="integer">
  End of the time range as a Unix timestamp (seconds). Defaults to now.
</ParamField>

### Example Request

<Tabs>
  <Tab title="curl">
    ```bash
    curl "https://md.kairos.trade/v1/candles?provider=polymarket&contract_id=71828abcd...&resolution=1h&from=1719792000&to=1719878400"
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import requests

    params = {
        "provider": "polymarket",
        "contract_id": "71828abcd...",
        "resolution": "1h",
        "from": 1719792000,
        "to": 1719878400,
    }

    response = requests.get("https://md.kairos.trade/v1/candles", params=params)
    candles = response.json()["candles"]

    for candle in candles:
        print(f"{candle['timestamp']}  O:{candle['open']}  H:{candle['high']}  L:{candle['low']}  C:{candle['close']}  V:{candle['volume']}")
    ```
  </Tab>
  <Tab title="JavaScript">
    ```javascript
    const params = new URLSearchParams({
      provider: "polymarket",
      contract_id: "71828abcd...",
      resolution: "1h",
      from: "1719792000",
      to: "1719878400",
    });

    const response = await fetch(`https://md.kairos.trade/v1/candles?${params}`);
    const { candles } = await response.json();

    candles.forEach(c => {
      console.log(`${c.timestamp}  O:${c.open}  H:${c.high}  L:${c.low}  C:${c.close}  V:${c.volume}`);
    });
    ```
  </Tab>
</Tabs>

### Response Fields

<ResponseField name="provider" type="string">
  The venue these candles originate from.
</ResponseField>

<ResponseField name="contract_id" type="string">
  The contract ID as passed in the request.
</ResponseField>

<ResponseField name="resolution" type="string">
  The candle resolution as passed in the request.
</ResponseField>

<ResponseField name="candles" type="array">
  Ordered array of OHLCV candle objects, sorted ascending by timestamp.

  <Expandable title="Candle object fields">
    <ResponseField name="timestamp" type="string">
      ISO 8601 UTC timestamp marking the **open** of this candle bucket.
    </ResponseField>
    <ResponseField name="open" type="number">
      First trade price within the bucket, as a decimal (e.g. `0.68` = 68¢ on a $1-par binary).
    </ResponseField>
    <ResponseField name="high" type="number">
      Highest trade price within the bucket.
    </ResponseField>
    <ResponseField name="low" type="number">
      Lowest trade price within the bucket.
    </ResponseField>
    <ResponseField name="close" type="number">
      Last trade price within the bucket.
    </ResponseField>
    <ResponseField name="volume" type="number">
      Total notional volume traded within the bucket, in USD.
    </ResponseField>
  </Expandable>
</ResponseField>

<Note>
  Candle buckets with zero trades during the period are omitted from the response. If you need a continuous series for charting, fill gaps with the previous bucket's `close` value.
</Note>

## Batch Fetch Candles

Retrieve OHLCV candle series for up to 200 contracts in a single request. All contracts in the batch can span different providers and resolutions — each entry in the request is independently specified.

```
POST /v1/candles/batch
```

### Request Body

<ParamField body="requests" type="array of objects" required>
  Array of candle request objects. Maximum 200 entries per call.

  <Expandable title="Candle request object fields">
    <ParamField body="provider" type="string" required>
      The venue the contract belongs to.
    </ParamField>
    <ParamField body="contract_id" type="string" required>
      The contract (token) ID to retrieve candles for.
    </ParamField>
    <ParamField body="resolution" type="string" required>
      Candle bucket size. One of `1m`, `5m`, `1h`, `1d`.
    </ParamField>
    <ParamField body="from" type="integer">
      Start of the time range as a Unix timestamp (seconds).
    </ParamField>
    <ParamField body="to" type="integer">
      End of the time range as a Unix timestamp (seconds).
    </ParamField>
  </Expandable>
</ParamField>

### Example Request

<Tabs>
  <Tab title="curl">
    ```bash
    curl -X POST "https://md.kairos.trade/v1/candles/batch" \
      -H "Content-Type: application/json" \
      -d '{
        "requests": [
          {
            "provider": "polymarket",
            "contract_id": "71828abcd...",
            "resolution": "1h",
            "from": 1719792000,
            "to": 1719878400
          },
          {
            "provider": "kalshi",
            "contract_id": "FED-25JUN-T4.75-YES",
            "resolution": "1d",
            "from": 1717200000,
            "to": 1719878400
          }
        ]
      }'
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import requests

    payload = {
        "requests": [
            {
                "provider": "polymarket",
                "contract_id": "71828abcd...",
                "resolution": "1h",
                "from": 1719792000,
                "to": 1719878400,
            },
            {
                "provider": "kalshi",
                "contract_id": "FED-25JUN-T4.75-YES",
                "resolution": "1d",
                "from": 1717200000,
                "to": 1719878400,
            },
        ]
    }

    response = requests.post(
        "https://md.kairos.trade/v1/candles/batch",
        json=payload,
    )
    results = response.json()["results"]

    for series in results:
        print(f"{series['provider']} / {series['contract_id']}: {len(series['candles'])} candles")
    ```
  </Tab>
</Tabs>

### Response Fields

<ResponseField name="results" type="array">
  Array of candle series responses. The order matches the input `requests` array.

  <Expandable title="Series response fields">
    <ResponseField name="provider" type="string">
      The venue for this series.
    </ResponseField>
    <ResponseField name="contract_id" type="string">
      The contract ID for this series.
    </ResponseField>
    <ResponseField name="resolution" type="string">
      The candle resolution for this series.
    </ResponseField>
    <ResponseField name="candles" type="array">
      Ordered array of OHLCV candle objects. See the [single candle response fields](#response-fields) for field definitions.
    </ResponseField>
    <ResponseField name="error" type="string | null">
      If a specific contract could not be resolved or had no data, this field contains a human-readable error message. Other entries in the batch are unaffected.
    </ResponseField>
  </Expandable>
</ResponseField>

<Tip>
  Use the batch endpoint when building dashboards or portfolio views — it reduces HTTP overhead significantly compared to one request per contract.
</Tip>
