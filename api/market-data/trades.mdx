The Trades endpoints expose the raw execution tape and derived volume analytics for any contract Kairos tracks. Use the trade tape to audit recent activity, detect large block trades, or build your own candles. Use the metrics endpoint to quickly gauge market sentiment — how much volume is flowing toward the Yes side versus the No side — within a rolling time window. No authentication is required.

---

## Get Recent Trade Tape

Retrieve the most recent executed trades for a single contract in reverse-chronological order (newest first).

```
GET /v1/trades
```

### Parameters

<ParamField query="provider" type="string" required>
  The venue the contract belongs to. Accepted values: `polymarket`, `kalshi`, `predictfun`.
</ParamField>

<ParamField query="contract_id" type="string" required>
  The contract (token) ID to retrieve trades for.
</ParamField>

<ParamField query="limit" type="integer">
  Maximum number of trades to return. Defaults to `50`. Maximum is `500`.
</ParamField>

<ParamField query="before" type="integer">
  Return only trades that occurred before this Unix timestamp (seconds). Use with the oldest `timestamp` from a previous response to paginate backward through the tape.
</ParamField>

### Example Request

<Tabs>
  <Tab title="curl">
    ```bash
    curl "https://md.kairos.trade/v1/trades?provider=polymarket&contract_id=71828abcd...&limit=10"
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import requests

    params = {
        "provider": "polymarket",
        "contract_id": "71828abcd...",
        "limit": 10,
    }

    response = requests.get("https://md.kairos.trade/v1/trades", params=params)
    trades = response.json()["trades"]

    for trade in trades:
        print(f"{trade['timestamp']}  {trade['side']}  {trade['size']} @ {trade['price']}")
    ```
  </Tab>
  <Tab title="JavaScript">

### Response Fields

<ResponseField name="provider" type="string">
  The venue these trades originate from.
</ResponseField>

<ResponseField name="contract_id" type="string">
  The contract ID as passed in the request.
</ResponseField>

<ResponseField name="trades" type="array">
  Array of trade objects, ordered newest-first.

  <Expandable title="Trade object fields">
    <ResponseField name="trade_id" type="string">
      Unique identifier for this trade record within Kairos.
    </ResponseField>
    <ResponseField name="price" type="number">
      Execution price of the trade, as a decimal between `0.0` and `1.0` (representing cents on a $1-par binary contract).
    </ResponseField>
    <ResponseField name="size" type="number">
      Notional size of the trade in USD.
    </ResponseField>
    <ResponseField name="side" type="string">
      The direction of the trade from the maker's perspective. One of `buy` or `sell`.
    </ResponseField>
    <ResponseField name="taker_side" type="string">
      The direction of the trade from the taker's (aggressor's) perspective. One of `buy` or `sell`. When `taker_side` is `buy`, the taker lifted an offer; when `sell`, the taker hit a bid.
    </ResponseField>
    <ResponseField name="timestamp" type="string">
      ISO 8601 UTC timestamp when the trade was executed.
    </ResponseField>
  </Expandable>
</ResponseField>

### Paginating the Tape

To walk backward through trade history, take the `timestamp` of the oldest trade in your current response, convert it to a Unix timestamp, and pass it as the `before` parameter on your next request:

```python
import requests
from datetime import datetime, timezone

def get_all_trades(provider, contract_id, limit_per_page=500):
    all_trades = []
    before = None

    while True:
        params = {
            "provider": provider,
            "contract_id": contract_id,
            "limit": limit_per_page,
        }
        if before is not None:
            params["before"] = before

        response = requests.get("https://md.kairos.trade/v1/trades", params=params)
        trades = response.json()["trades"]

        if not trades:
            break

        all_trades.extend(trades)

        # Parse the oldest trade timestamp and use it as the next cursor
        oldest_ts = trades[-1]["timestamp"]
        before = int(datetime.fromisoformat(oldest_ts.replace("Z", "+00:00")).timestamp())

    return all_trades
```

## Get Trade Volume Metrics

Retrieve aggregate volume and outcome-pressure statistics for a single contract over a rolling time window. This endpoint condenses the raw tape into actionable directional signals — how much volume is flowing toward Yes (buy pressure) versus No (sell pressure).

```
GET /v1/trades/metrics
```

### Parameters

<ParamField query="provider" type="string" required>
  The venue the contract belongs to.
</ParamField>

<ParamField query="contract_id" type="string" required>
  The contract (token) ID to compute metrics for.
</ParamField>

<ParamField query="window" type="string" required>
  Rolling time window for the aggregation. One of `1h`, `4h`, `24h`.
</ParamField>

### Example Request

<Tabs>
  <Tab title="curl">
    ```bash
    curl "https://md.kairos.trade/v1/trades/metrics?provider=polymarket&contract_id=71828abcd...&window=24h"
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import requests

    params = {
        "provider": "polymarket",
        "contract_id": "71828abcd...",
        "window": "24h",
    }

    response = requests.get("https://md.kairos.trade/v1/trades/metrics", params=params)
    metrics = response.json()

    print(f"24h volume: ${metrics['volume']:,.2f}")
    print(f"Buy pressure:  {metrics['buy_pressure'] * 100:.1f}%")
    print(f"Sell pressure: {metrics['sell_pressure'] * 100:.1f}%")
    ```
  </Tab>
</Tabs>

### Example Response

```json
{
  "provider": "polymarket",
  "contract_id": "71828abcd...",
  "window": "24h",
  "volume": 284500.00,
  "buy_volume": 184925.00,
  "sell_volume": 99575.00,
  "buy_pressure": 0.65,
  "sell_pressure": 0.35,
  "trade_count": 1423,
  "window_start": "2025-06-30T09:50:00Z",
  "window_end": "2025-07-01T09:50:00Z"
}
```

### Response Fields

<ResponseField name="provider" type="string">
  The venue these metrics originate from.
</ResponseField>

<ResponseField name="contract_id" type="string">
  The contract ID as passed in the request.
</ResponseField>

<ResponseField name="window" type="string">
  The rolling window as passed in the request.
</ResponseField>

<ResponseField name="volume" type="number">
  Total notional volume (buy + sell) traded within the window, in USD.
</ResponseField>

<ResponseField name="buy_volume" type="number">
  Total notional volume of taker-buy trades within the window, in USD. Taker buys represent demand for the outcome token — participants lifting ask prices.
</ResponseField>

<ResponseField name="sell_volume" type="number">
  Total notional volume of taker-sell trades within the window, in USD. Taker sells represent supply pressure — participants hitting bid prices.
</ResponseField>

<ResponseField name="buy_pressure" type="number">
  Fraction of total volume that was taker-buy, between `0.0` and `1.0`. Values above `0.5` indicate net buying pressure.
</ResponseField>

<ResponseField name="sell_pressure" type="number">
  Fraction of total volume that was taker-sell, between `0.0` and `1.0`. `buy_pressure + sell_pressure = 1.0`.
</ResponseField>

<ResponseField name="trade_count" type="integer">
  Total number of individual trades executed within the window.
</ResponseField>

<ResponseField name="window_start" type="string">
  ISO 8601 UTC timestamp marking the start of the aggregation window.
</ResponseField>

<ResponseField name="window_end" type="string">
  ISO 8601 UTC timestamp marking the end of the aggregation window (approximately now).
</ResponseField>

<Info>
  `buy_pressure` and `sell_pressure` are computed from **taker** order flow, which is a standard measure of directional conviction. A spike in `buy_pressure` alongside rising price is a stronger signal than price movement alone.
</Info>

## WebSocket Alternative

Polling `/v1/trades` on a tight loop is inefficient. For latency-sensitive applications, subscribe to the trade stream over the [Market Data WebSocket](https://app.kairos.trade/docs/websocket/market-data-websocket), which pushes each trade to you the moment Kairos ingests it.
