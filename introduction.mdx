Kairos is a unified trading platform that connects you to every major prediction market and perpetuals venue through a single, consistent API surface. Instead of integrating with Polymarket, Kalshi, Predict.fun, and Hyperliquid separately — each with its own authentication, data formats, and order flow — you use Kairos once and trade everywhere.

## Supported Venues

Kairos routes orders and streams data across the following venues:

- **Polymarket** — the world's largest on-chain prediction market (USDC on Polygon)
- **Kalshi** — regulated US prediction market (CFTC-designated contract market)
- **Predict.fun** — prediction market with native combo/parlay support
- **Opinion** — emerging prediction market venue
- **Hyperliquid** — perpetuals DEX for leveraged positions on crypto and more

## The Four APIs

Kairos exposes four purpose-built APIs. Every API lives at its own base URL and is documented separately, but they share the same authentication scheme and data conventions.

| API | Base URL | Auth Required | Endpoints | Description |
|-----|----------|:---:|:---------:|-------------|
| **Market Data API** | `md.kairos.trade` | No | 15 | Real-time and historical market data, candles, trades, and perpetual snapshots — free, no signup |
| **Data API** | `data.kairos.trade` | Yes | 68 | Full data plane: search, sports, trader analytics, PnL, discovery, and enriched market metadata |
| **Execution API** | `execution.kairos.trade` | Yes | 59 | Order entry and cancellation, smart routing, combos/parlays, onboarding, and self-custody EIP-712 signing |
| **Agora Auction API** | `agora.kairos.trade` | Yes | 13 | Private institutional auction house with firm-quote RFQ and real-time WebSocket event streams |

Together these APIs expose **155 endpoints** covering every stage of the trading lifecycle.

## Market Data API

The Market Data API (`md.kairos.trade`) is completely free — no account, no API key, no rate-limit headers to manage for casual use. It provides:

- **Markets** — paginate active markets for any provider, fetch by ID, or resolve venue-specific identifiers
- **Candles** — OHLCV series for a single contract or batched up to 200 contracts in one request
- **Trades** — recent tape and aggregate volume/pressure metrics
- **Marks** — latest mark price (last-trade price) for up to 200 contract/token pairs
- **Resolutions** — batch resolution fractions and full lifecycle timelines
- **Perpetuals** — live snapshots for Hyperliquid and other perp venues

## Data API

The Data API (`data.kairos.trade`) is the full Kairos data plane. Authenticated callers can access:

- **Search** — full-text market search, autocomplete, URL resolution, and screener queries
- **Discover** — paginated event-grouped market lists, trending movers, and expiring-soon feeds
- **Sports** — cross-platform matched markets, live games, tournament brackets, and TxOdds fixtures
- **Trader Analytics** — per-wallet PnL history, positions, and trade history (some endpoints free)
- **PnL** — merged PnL across wallets and providers, live per-market hover data
- **Candles & Trades** — higher-throughput batched candle and trade endpoints with broader filters

## Execution API

The Execution API (`execution.kairos.trade`) handles every order lifecycle event:

- **Orders** — submit, list, fetch, cancel single or batch, cancel-all, fee quotes
- **Routing** — price and execute cross-venue split orders across linked market pairs
- **Combos** — quote, execute, cash out, and redeem Polymarket parlays
- **Onboarding** — enable trading on each venue (Polymarket CLOB credentials, Kalshi API keys, Predict.fun approvals, Opinion)
- **Self-custody** — EIP-712 intent/submit flow so your private key never leaves your client
- **Hyperliquid** — typed-data withdraw and spot↔perp transfer helpers
- **CTF** — split, merge, and redeem outcome token sets

## Agora Auction API

The Agora Auction API (`agora.kairos.trade`) is a private institutional venue for block-size trades:

- Create and manage private auctions with capacity preflight checks
- Invite makers to submit or revise firm, executable quotes
- Stream the complete audit timeline over WebSocket
- Role-filtered views ensure each participant sees only what they're entitled to
